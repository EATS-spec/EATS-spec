# Hey, I’m Shane 👋

I built **Pickup Hunt** with Codex after a launch-day iPhone search turned into a family project. It helps you find your preferred phone at nearby Apple Stores and watch for pickup availability, with opt-in background alerts.

**Good phones. Worth the hunt.**
